## 👋 About

I design and ship **complete products** — from database schema and REST APIs to the deployed server that runs them. Most of my work is real, client-facing software running in production: multi-role dashboards, content platforms, business management systems, and AI-powered tools.

I care about the parts people skip — typed boundaries, validated inputs, indexed queries, background workers, and a deploy that doesn't fall over on Monday morning.

```text
Frontend  →  Next.js (App Router) · React · TypeScript · Tailwind CSS
Backend   →  Node.js · Express · TypeScript · MongoDB / Mongoose
AI Layer  →  LangChain · LangGraph · RAG · Vector DBs · Agentic workflows
Delivery  →  Docker · Nginx · PM2 · VPS · CI-ready deployments
```

## ⚙️ How I Build

| Area | Approach |
|:--|:--|
| **Architecture** | Clean separation of routes → controllers → services → models, typed end-to-end with TypeScript |
| **API Design** | RESTful and versioned, validated at the boundary with **Zod** / express-validator |
| **Security** | JWT auth flows, bcrypt hashing, Helmet, rate limiting, input sanitisation, signed upload URLs |
| **Performance** | Server-side rendering, image optimisation, response compression, caching and indexed queries |
| **Background Work** | Cron jobs, task queues and worker services for anything that shouldn't block a request |
| **Deployment** | Dockerised services behind Nginx, process-managed with PM2, on managed cloud or a bare VPS |
| **Documentation** | Every system I hand over ships with setup, environment and deployment docs |
